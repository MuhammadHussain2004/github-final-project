# Code of Conduct

## Our Pledge

We pledge to make participation in this project a respectful experience for everyone.

## Our Standards

Our community welcomes constructive discussion, clear communication, empathy, and respect. Harassment, discrimination, personal attacks, and disruptive behavior are not acceptable.

## Enforcement Responsibilities

Project maintainers are responsible for clarifying and enforcing these standards and may remove or edit contributions that violate them.

## Scope

This Code of Conduct applies in project spaces and whenever an individual officially represents the project.
